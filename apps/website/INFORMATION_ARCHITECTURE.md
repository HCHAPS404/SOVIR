# Sitio público — arquitectura de información

Estado: mapa. No hay aplicación Next.js. Cada ruta espera copy verificable y un nodo Figma real.

| Ruta | Función |
|---|---|
| `/` | Promesa comprobable y acceso o descarga |
| `/product` | Qué observa y qué no observa |
| `/how-it-works` | Recorrido local, límites y costo |
| `/platforms` | Cobertura por sistema, sin afirmar lo no probado |
| `/security` | Modelo de amenaza del propio agente |
| `/privacy` | Retención, revocación y derechos |
| `/trust` | Separación entre captura, nube y compartir indicadores |
| `/enterprise` | Agregados. Sin vigilancia individual |
| `/pricing` | Solo precios que tú hayas aprobado |
| `/research` | Fuentes, método y fecha |
| `/download` | Binarios firmados cuando existan |
| `/sign-in` | Entrada. La consola vive en otro sitio |

El sitio no usa el layout de la consola. El inicio de sesión no se indexa como página de producto.
