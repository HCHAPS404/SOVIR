# 02 — Escritorio con portátil

**Archivo destino:** `apps/website/public/photos/escritorio-portatil.webp` · **Aspecto:** 3:4 (vertical)

## Prompt (EN)

```
Editorial interior photograph, a clean wooden desk seen from a slight
three-quarter angle, an open laptop in sharp focus occupying the middle
ground, beside it a closed notebook, a pen and a small ceramic mug, soft
afternoon light through a window out of frame, warm neutral grade — cream,
ink black, soft amber — matte editorial look, shallow depth of field
(35mm, f/2.8).

The laptop screen shows a dark-themed web console at a readable size:
near-black interface, cream text, left sidebar with a small logo and four
navigation items in Spanish ("Resumen", "Avisos de seguridad" highlighted,
"Mis dispositivos", "Privacidad y permisos"), main area titled in an
elegant serif "Avisos de seguridad" with two dark cards showing amber
"nuevo" badges and small Spanish captions. Minimal, calm, professional.

A green plant softly blurred at the frame edge, cozy home-office feel,
photorealistic, mirrorless camera, subtle film grain.
```

## Negative prompt

```
English UI text, gibberish interface, cluttered desk, RGB gaming lights,
neon, corporate glass office, holographic elements, person typing,
visible logos (Apple/Dell/Windows), screen glare, oversaturated colors,
watermark, cartoon look
```

## Notas (ES)

- Esta foto es la que "prueba" la consola — la pantalla tiene que leerse
  como la referencia aunque sea con texto pequeño.
- Si el texto sale deformado: pantalla negra + componer la captura real
  encima (la referencia ya está en perspectiva casi frontal).
